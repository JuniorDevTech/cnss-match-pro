# CNSS Match Pro

Application web de rapprochement CNSS développée avec React.js.

## Fonctionnalités

- Import des fichiers BDS
- Import du personnel
- Analyse automatique CNSS
- Tableau de bord
- Exports Excel
- Assistant IA intégré

## Technologies

- React.js
- Tailwind CSS
- Zustand
- SheetJS
- React Dropzone
- React Hot Toast

## Installation

```bash
npm install
npm run dev
```
